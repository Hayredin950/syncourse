# 📱 Syncourse Mobile (Flutter)

The Flutter client for Syncourse — same design tokens and API as the web app.
This folder contains the full Dart source (`lib/`) and `pubspec.yaml`. Platform
folders (android/ios/) are generated by the Flutter toolchain.

## Run it

```bash
# 1. generate platform scaffolding (android/, ios/, etc.) — keeps existing lib/
flutter create .

# 2. install dependencies
flutter pub get

# 3. point the app at your API (defaults to http://localhost:4000)
flutter run --dart-define=API_URL=http://localhost:4000
```

Then run the backend (`npm run dev:api` from the repo root) and sign in with
`demo@syncourse.app` / `demo1234`.

## What's implemented

Bottom navigation shell with 5 tabs — **Home · Browse · Search · Learning · Me**
(mirrors the reference app's 4-tab nav, with Learning added for course progress):

| Screen | Notes |
|---|---|
| `HomeScreen` | Trending / Latest / Top rated rails + "Best of {org}" + featured paths, from `/api/home` |
| `BrowseScreen` | Sortable course list (top-rated / most-enrolled / A–Z) |
| `SearchScreen` | Live search-as-you-type (debounced) + "Everyone is searching" trending chips |
| `CourseDetailScreen` | Banner, meta row, tags, expandable description, Enroll & start, save/like, downloads widget, lecturer & organization, curriculum (sections → lessons), reviews |
| `LessonScreen` | Signed video URL flow, mark-complete (progress %), downloadable files with BEST badge, notes with cheat-sheet badges |
| `MyLearningScreen` | Tabs: In progress / Completed / Wishlist / Liked with progress bars |
| `ListsScreen` + `ListDetailScreen` | Create lists, public/private visibility, list contents |
| `PremiumScreen` | Plans in ETB with BEST VALUE badge + benefit rows |
| `ProfileScreen` | Avatar, 2×3 stat grid, subscription, circles, settings, sign out |
| `CirclesScreen` | Social activity feed (what people you follow are learning) |
| `AuthScreen` | Email/password login + register (JWT via shared_preferences), Google button stub |

All API calls go through `lib/api.dart` — `Authorization: Bearer <token>`, JSON
handling, error mapping — mirroring the web client (`apps/web/src/lib/api.ts`).
